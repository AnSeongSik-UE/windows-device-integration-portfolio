# Windows 장비 연동 개발 포트폴리오

C++·Qt 기반 조이패드 모터 제어와 상태 모니터링 UI 사례도 포함합니다.

[Windows 장비 연동 개발 포트폴리오 보기](https://anseongsik-ue.github.io/windows-device-integration-portfolio/)

이 저장소에는 공개용 정적 페이지와 비식별 처리된 화면 이미지만 포함합니다. 회사 원본 소스와 실제 IP·포트·인증 정보는 포함하지 않습니다.
